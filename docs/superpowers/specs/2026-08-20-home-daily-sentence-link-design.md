# 首頁「今日一句」位置與字卡連結設計

日期：2026-08-20

## 目標

把首頁的「今日一句」移到「聲音熱身」上方，並讓中文翻譯可以開啟對應字卡。互動範圍只限中文文字，避免整張卡片可點造成誤觸。

## 驗收條件

1. 首頁內容順序為：主功能卡、「今日一句」、聲音熱身與其他任務、本週進度、成就。
2. 「今日一句」的泰文、標題與卡片空白處不可點擊。
3. 只有中文翻譯是可辨識且可鍵盤操作的文字連結，點擊範圍不額外向外擴張。
4. 點擊中文後，使用現有 `?card=<lessonId>:<thai>` deep link 開啟正確課程的正確字卡。
5. 句子內容未載入或資料不完整時，不產生失效連結。
6. 自動測試通過，Service Worker cache 版本更新，部署後以 production URL 實際讀回驗證。

## 版面與互動

「今日一句」區塊由目前首頁底部移到主功能卡之後、任務清單之前，因此會直接出現在「聲音熱身」上方。卡片外觀、泰文與標題維持原樣。

中文翻譯改成原生 `<a>` 連結。連結保留目前文字大小與低調色彩，只加入足以辨識的底線／顏色，以及鍵盤 focus 樣式。連結不加額外 padding，也不替整張卡片註冊 click handler，將誤觸範圍限制在中文字本身。

## 資料流

1. `pickDailySentence()` 繼續回傳 `{ lesson, card }`。
2. 首頁非同步取得資料後，以 `lesson.id` 與 `card.thai` 組成既有 `card` query parameter。
3. query parameter 交由 `URLSearchParams` 編碼，避免泰文、空白或特殊字元破壞 URL。
4. 瀏覽器依原生連結重新載入頁面；現有 `src/app.js` deep-link 流程切到字卡模式、載入課程並找到泰文相符的字卡。
5. 若缺少課程 ID、泰文或中文，不建立中文連結，保留不可點擊的 fallback 顯示。

這次沿用 Telegram 推播已使用的 deep-link 合約，不新增 API，也不另做一套頁內導覽狀態。

## 修改範圍

- `src/home.js`：調整區塊位置、建立中文連結並安全編碼 deep link。
- `styles.css`：補上中文文字連結與鍵盤 focus 樣式。
- `tests/`：驗證 deep-link 編碼、區塊順序與只有中文可點。
- `sw.js`：依專案規範更新 cache 版本。

## 不在本次範圍

- 不修改 Telegram 推播內容或排程。
- 不改每日一句的抽選規則。
- 不讓整張「今日一句」卡片可點。
- 不新增 AJAX／SPA 導覽機制。
- 不調整其他首頁卡片的樣式或順序。

## 驗證方式

1. 執行相關單元測試與完整測試套件。
2. 檢查產生的 URL 能正確編碼並由既有 deep-link parser 還原。
3. 在行動版寬度確認「今日一句」位於「聲音熱身」上方，且只有中文呈現連結互動。
4. 實際點擊中文，確認開到相同泰文的目標字卡。
5. 部署後讀回 production HTML、JavaScript 與 Service Worker 版本，確認線上內容與 commit 一致。
