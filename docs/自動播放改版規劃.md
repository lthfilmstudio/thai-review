# thai-review 自動播放改版規劃

**日期**：2026-06-19 13:37（Asia/Taipei）
**狀態**：已完成並部署（2026-06-19）
**影響 repo**：`thai-review`（前端）、`lth-tts-proxy`（中文語音，需 deploy）

## 實作補強

- 跟讀時間改用泰文實際播放長度：`max(1.5 秒, 實際時間 × 1.5)`；字數估算只當無法取得 duration 時的 fallback。
- 舊版 localStorage 設定做一次 migration，既有裝置的 `gap: 2` 會切到 `auto`，之後仍可手動選固定秒數。
- 中文使用 `cmn-TW-Wavenet-A`，瀏覽器 fallback 使用 `zh-TW`；中文固定正常語速，泰文沿用使用者語速。
- `stopListen()` 現在會取消雲端 MP3 與瀏覽器語音，並阻止舊的非同步播放流程繼續推進。
- Worker CORS 加入 `https://thai-review.lthfilmstudio.com`，未知來源不再收到其他網域的 allow-origin。
- 前端 Service Worker cache 升為 `v41`，Worker 與 Cloudflare Pages 均已部署。

## 一、這次要改的兩件事

1. **跟讀時間跟著單字 / 例句長短變化** — 跟讀空白 = 老師語音時間 × 1.5（比老師長一半）。
2. **自動播放先唸中文翻譯** — 每張卡先用老師語音唸中文意思，再進泰文語音 + 跟讀。

---

## 二、現況

自動播放邏輯在 `src/listen.js`，每張卡流程：

```
Phase 1 老師語音(泰文)  →  Phase 2 跟讀空白  →  重複 N 次  →  換下一張
```

- 跟讀空白現有算法（`listen.js:110`）：`auto` 模式 = `max(1.5 秒, 老師時間 × 1.3)`。
- 但設定預設是固定 `gap: 2`（2 秒，`state.js:153`），所以多數情況跟讀時間是死的、不隨長短變化。
- 老師時間用 `estimateTeacherMs()` 估算（`tts.js:138`）：`字數 × 120ms`，夾在 800～5000ms。短單字短、長例句長，本來就會不同。

---

## 三、第 1 點：跟讀時間 = 老師時間 × 1.5

**難度低 · 純前端 · 單檔 · 低風險**

### 改動
| 檔案 | 改什麼 |
|------|--------|
| `src/listen.js` | `auto` 公式由 `老師時間 × 1.3` 改成 `老師時間 × 1.5` |
| `src/state.js` | 預設 `gap` 由 `2` 改成 `'auto'`，跟讀時間才會真的跟著長短走 |

### 決策點
- 要讓「跟長短變化」生效，預設一定要走 `auto`。手動指定固定秒數的選項保留，只是預設改成自動。

### 備註（這次不做）
- `estimateTeacherMs` 是用字數「猜」的，不是真實音檔長度。雲端 MP3 其實有真實 `duration`，要更精準可改用真實長度，但屬於另一層改動，先不碰。

### 驗證
- 自動播放短單字 → 跟讀空白短；長例句 → 跟讀空白明顯變長，且約為老師唸完時間的 1.5 倍。

## 四、第 2 點：自動播放先唸中文翻譯

**難度中 · 跨 repo · 需要重新 deploy proxy**

### 卡點：TTS proxy 現在唸不出中文
`lth-tts-proxy/src/index.ts`：
- `ALLOWED_VOICES`（line 27）只有 4 個泰文語音，傳其他語音會被打回泰文。
- `languageCode: 'th-TH'` 寫死（line 126）→ 就算丟中文字，也用泰文引擎唸，結果是亂的。

### A. lth-tts-proxy（改完要 `wrangler deploy`，git push ≠ 部署）
1. `ALLOWED_VOICES` 加入台灣中文語音（建議 `cmn-TW-Wavenet-A` 台灣女聲）。
2. `languageCode` 改成從 voice 前綴推導：`th-TH-*` → `th-TH`、`cmn-TW-*` → `cmn-TW`，不要寫死。
3. deploy 後用 curl 確認中文語音真的唸得出來，再接前端。

### B. thai-review 前端
1. `src/tts.js`：新增可指定「文字 + 語音」的播放函式（現有 `speakWithPromise` 寫死唸 `card.thai` + 泰文語音）。
2. `src/listen.js` 的 `runListenStep`：每張卡第一次（`repeatCount === 0`）先用中文語音唸 `card.zh`，唸完再進原本泰文老師語音 + 跟讀迴圈。加 guard 確保中文只在「換卡」唸一次，不是每次重複都唸。
3. UI 小調整：唸中文那段給個提示（借用老師進度條，或加一個「老師唸中文」phase）。可最小化。

### 新流程
```
換卡 → 老師唸中文意思(一次) → 老師語音(泰文) → 跟讀空白 → 重複 N 次 → 換下一張
```

### 驗證
- 自動播放換到新卡時，先聽到中文翻譯，再進泰文；同一張卡重複 N 次時，中文只唸一次。
